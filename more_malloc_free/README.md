# C - More malloc, free

This directory contains more projects about dynamic memory allocation in C
using `malloc` and `free`.

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file with all function prototypes |
| `0-malloc_checked.c` | Allocates memory using malloc, exits with status 98 on failure |
| `1-string_nconcat.c` | Concatenates s1 and the first n bytes of s2 into new memory |
| `2-calloc.c` | Allocates memory for an array of nmemb elements and sets it to zero |
| `3-array_range.c` | Creates an array of integers from min to max (both included) |
