# C - Structures, typedef

This directory contains projects about structures and `typedef` in C.

## Files

| File | Description |
|------|-------------|
| `dog.h` | Header file defining `struct dog` (name, age, owner) |
| `1-init_dog.c` | Initializes a variable of type struct dog |
| `2-print_dog.c` | Prints a struct dog, using (nil) for NULL elements |
